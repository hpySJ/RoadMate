# RoadMate AI 제출 요약

## 최종 구성

Qwen3-8B Q4_K_M(`MODEL_PROFILE=8b-q4`), `translate-v11`, 문장부호 없는 스페인어 입력의 `¿?` 복원 규칙으로 고정함. 복원 시작 표현에 `cuándo`, `quién`, `quiénes` 포함함. 문장부호 있는 입력은 유지함. LoRA 어댑터 없음. 두 단계 출력·문체·현장 용어·다듬기 실험 옵션은 미채택함.

원본 Qwen3-8B 모델은 [Apache-2.0](https://huggingface.co/Qwen/Qwen3-8B/blob/b968826d9c46dd6066d109eabc6255188de91218/LICENSE). 원본·GGUF revision과 GGUF 파일 SHA256은 `models/manifest.qwen3-8b.json`에 고정함. 라이선스·고지 보존 필요함.

## 구조와 앱 연결

`Android 앱 → AI 서버 POST /translate → llama-server`

모델 출력은 AI 서버 검사를 거쳐 앱으로 반환함. 앱 요청은 `text`, `from`, `to`, `situation`, 성공 응답은 `{"text":"번역문"}` 형식임. 재질문 응답은 `clarification`, `clarification_locale`만 포함하며 `text`를 생략함. 현재 앱은 해당 경우 문장 카드로 대체함. 내부 `/internal/v1/*` API도 유지함.

AI 서버는 `127.0.0.1:8000`, llama-server는 `127.0.0.1:8081` 사용함. `/translate`는 토큰 없는 로컬 시연용 경로임. 앱의 URL·네트워크 설정은 앱 담당 범위이며 이번 작업에서 Android 코드는 변경하지 않음.

## 평가 결과

자동 통과율은 검사기·평가 기대값 통과 비율임. 문장 뜻과 자연스러움의 정확도 보증은 아님. 아래 과거 수치는 사용자 제공 보고에 근거함. 이번 정리에서 원시 모델 출력은 재검토하지 않음.

### 과거 자동 평가 — 4B `repair-v9`

| 평가셋 | 번역 자동 통과 | 통과율 |
|---|---:|---:|
| dev | 73/75 | 97.3% |
| general | 157/160 | 98.1% |
| general_es | 90/90 | 100% |
| naturalness.dev | 20/20 | 100% |

위 결과는 과거 4B 실행임. 최종 8B v11 설정의 성적으로 사용하면 안 됨.

### 8B 선택 근거 — `34bfd43`, AI 검토(참고)

Claude 블라인드 검토 결과임. 사람 검수 결과로 표시하지 않음.

| 모델 | 좋음 | 어색함 | 나쁨 | 뜻 오류 |
|---|---:|---:|---:|---:|
| 4B | 64% | 30% | 6% | 16/268 |
| 8B | 71% | 27% | 2% | 5/269 |

해당 비교에서 8B 목적지 자동 통과 20/20(100%), general p95 약 511ms. 이후 LoRA 비교의 뜻 오류 7건 기준과는 표본·실험이 다름. 표본 수가 다른 집계를 같은 행 개선량으로 해석하면 안 됨.

### STT 견고성

사용자 제공 STT 비교 오류 건수 **21→12**. 이번 정리에서 분모·원시 자료·오류 분류 기준은 재확인하지 않음. 정확도 백분율로 환산하지 않으며, 사람 검수나 최종 잠근 시험 결과와 구분해야 함.

### 최종 실행 결과 — 실행 후 기입

최종 설정으로 같은 서버에서 평가해야 함. 잠근 시험 `test.locked.v2`는 원문·reference·기대값 44행 독립 검토 완료, 모두 승인함. 검토 시각은 `2026-11-10T07:30:46+09:00`. 모델 출력은 보지 않았으며 `reviewer="ai:claude+codex (human_reviewed=false)"`로 기록함. `--final` 실행은 한 번만 수행해야 함.

| general | 실행 후 기입 | 실행 후 기입 | 실행 후 기입 | 최종 설정 실행 대기 |
| general_es | 실행 후 기입 | 실행 후 기입 | 실행 후 기입 | 최종 설정 실행 대기 |
| naturalness.dev | 실행 후 기입 | 실행 후 기입 | 실행 후 기입 | 최종 설정 실행 대기 |

명령은 [guide](guide.md)에 정리함. 잠근 시험 실행 후 결과·실행 설정·코드 식별자를 기록하고 팀 저장소용 후속 커밋 준비 필요함.

### 로컬 코드 검증

2026-11-10 통합 테스트 1,961건·주행 시나리오 통과함. 세 프로필 토큰 예산도 프로필별 759건 통과함. 보고서 `run/verify-243be347fb/report.json`. 최종 DLPC 명령은 Bash 구문만 검사함. 실제 모델 품질·잠근 시험 성적과 별개임.

## LoRA 종료

아래 품질 수치는 사용자 제공 **AI 검토(참고)** 요약임.

| 선생 모델 | 결과 | 종료 사유 |
|---|---|---|
| 14B | 같은 행 뜻 오류 7→7 | 뜻 오류 개선 없음 |
| 32B | 자연스러움 개선, 같은 행 뜻 오류 7→6. 학습 표본 나쁨 6.7%, 스페인어 9% | 학습 자료 품질 기준 미달 |
| 8B 자기 선생 | 학습 표본 나쁨 8.0% | 학습 자료 품질 기준 미달 |

모두 채택 기준 미달로 종료함. 재현용 LoRA 도구 코드는 보존하되 추가 생성·학습은 진행하지 않음. 최종 배포에 어댑터를 포함하지 않음. LoRA 해시 보존을 위한 주석 정리 제약은 해제함. 모델 파일 무결성 검사는 유지함.

## 남은 한계

- 스페인어의 상황상 질문 중 규칙에 맞지 않는 표현은 평서문으로 번역될 수 있음. 반대로 문장부호 없는 `hay`, `ya` 평서문이 질문으로 복원될 수 있음.
- 실제 구어 표본에서 뜻 오류 약 8% 보고됨. AI 검토(참고)이며 표본·분모를 이번에 재확인하지 않음. 안전 검사기가 모든 의미 오류를 잡지는 못함.
- Pleos STT의 `won→one` 인식 오류는 수량과 구분하기 어려워 자동 보정하지 않음.
- `hi pass` 같은 고유명사 인식·번역 오류 가능성 남음.
- 프랑스어 미지원. 지원 언어는 한국어·영어·스페인어이며, 짧고 모호한 외국어의 원문 언어 판별에도 한계 있음.
- 시연에 사용할 GPU PC에서 실제 적재·지연·앱 음성 왕복 확인 필요함. DLPC 측정만으로 시연 PC 동작을 보장할 수 없음.
- 원어민·사람 검수 미완료. AI 검토를 사람 검수나 운전 중 안전성 인증으로 사용할 수 없음.
